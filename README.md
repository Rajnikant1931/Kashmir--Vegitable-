# Kashmir Vegitable v4 — Secure Admin Scaffold

## Firebase setup
1. Use Firebase project: kashmir-vegitable-5ebdb.
2. Enable Authentication > Sign-in method > Email/Password.
3. Create Firestore Database.
4. Deploy `firestore.rules`.
5. Create an admin user in Firebase Authentication.
6. In Firestore create `users/<ADMIN_UID>` with:
   - role: `admin`
   - name: `Admin`
7. Never allow the client to change its own role.

## Flutter setup
1. Install Flutter and FlutterFire CLI.
2. Run `flutter pub get`.
3. Run `flutterfire configure` and select project `kashmir-vegitable-5ebdb`.
4. Replace the placeholder Firebase options generated by FlutterFire.
5. Run `flutter run`.

## Included
- Email/password admin login
- Firestore role check
- Product list and stock toggle
- Add vegetable
- Order list and status changes
- Firestore security rules
